BYG DOPE WARS BFT 1.3.0 / WINDOWS X64

Installér Python 3.12 x64. Kør fra denne kildemappe:
  .\build.ps1

Scriptet opretter .build-env, installerer de fastlåste versioner i
requirements.txt, genererer BFT-grafik og kører alle regel-, Qt- og TLS-tests.
Derefter bygges EXE + _internal, som testes igen og pakkes i en komplet ZIP.
Testmiljøet skal tillade lokale TCP/UDP-forbindelser og Windows DPAPI.

Med et eksisterende isoleret Python 3.12 x64-miljø:
  .\build.ps1 -PythonExe 'C:\sti\venv\Scripts\python.exe' -SkipDependencyInstall
Brug kun SkipDependencyInstall, når pakkerne matcher requirements.txt.

Ekstra målinger og installer:
  .\build.ps1 -RunBalanceSimulation -RunLanBenchmark -InnoCompiler 'C:\sti\ISCC.exe'

RunBalanceSimulation kører 31 faste seeds for hver virksomhed og tidshorisont,
10.000 kontroldage og 100.000 mule-risikotræk. Den korte regressionsprøve
køres altid som del af test_game.py. Baseline fra 1.1.0 ligger i
baseline-balance.json. Forudsætninger og resultater: BALANCE-RESULTATER.txt.

RunLanBenchmark sammenligner 8 TLS-klienter i 60 sekunder pr. transportform,
med og uden forbindelsesgenbrug. Den bruger 0,1 sekund mellem polls for at
belaste mere end spillets normale 1 sekund. Qt-vinduet tegnes samtidig.
Resultatet måler p95, TLS-håndtryk, kvitteringer og GUI-timerens forsinkelse.
Kør på en ellers rolig pc. Kort funktionstest af samme vej kører altid.

InnoCompiler bygger den danske offline-installer efter accepttestene.
Den skal pege på Inno Setup 7.1.1 ISCC.exe (installerens afprøvede version).
Installationen er pr. Windows-bruger og kræver ikke administratorrettigheder.
Installer, EXE og afinstalleringsprogram er usignerede i den version.

Resultater:
  dist\DopeWars-BFT\DopeWars-BFT.exe og komplet _internal
  dist\DopeWars-BFT-1.3.0.zip
  dist\DopeWars-BFT-Setup-1.3.0.exe (når InnoCompiler er angivet)
  dist\reports\source-tests.json
  dist\reports\packaged-release-self-test.json
  dist\reports\packaged-self-test.json
  dist\reports\balance.json (ved RunBalanceSimulation)
  dist\reports\lan-performance.json (ved RunLanBenchmark)

Enkelte målinger kan også køres direkte:
  python simulate_balance.py --output dist/reports/balance.json
  python benchmark_lan.py --seconds 60
  python app.py --release-self-test dist/reports/source-tests.json
  python app.py --self-test dist/reports/ui-smoke.json

app.py er GUI, game.py er fælles regler, lan.py er autoritativ vært,
lan_ui.py er lobby/klient, og lan_discovery.py søger efter lokale spil.
Tests og simuleringsscripts medfølger i source sammen med specifikationen.
Biblioteker indlæses dynamisk fra _internal og har medfølgende licenser.
Windows-systemfonte medfølger ikke.

SignPath-workflowet kan kun signere den portable EXE efter projektgodkendelse
og godkendt signeringsopsætning. Det signerer ikke installeren i denne
ændring. Se SIGNERING.txt. Ingen pakker uploades af det lokale byggescript.

LINUX
Kør bash run-linux.sh for at starte eller bash run-linux.sh --test for at teste.
Testene bruger en midlertidig datamappe, som fjernes bagefter.
GitHub Actions tester samme kildekode på Ubuntu med Python 3.12 og Qt 6.8.3.
